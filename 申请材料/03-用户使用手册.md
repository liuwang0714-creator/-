# 瞻途电商交易系统软件 V1.0
## 用户使用手册

---

## 第 1 章 软件概述

「瞻途电商交易系统软件 V1.0」是一套面向管理员、商家、普通用户三类角色的电子商务交易系统，以「瞻途」为品牌名，以「前瞻未来 · 途享好物」为品牌口号，提供商品发布、在线下单、支付、发货、评价、即时通讯及后台运营管理功能。系统包含 Web 管理后台与微信小程序移动端两个客户端。

本手册面向系统使用者与运维人员，介绍软件的安装部署与各角色的操作流程。

### 1.1 品牌标识

- **品牌名称**：瞻途（ZHAN TU）
- **品牌口号**：前瞻未来 · 途享好物
- **品牌 Logo**：由品牌配置系统（`brand.js` + `BrandLogo.vue`）统一管理，在 Web 端首页、登录页、管理后台等位置统一展示

## 第 2 章 安装与部署

### 2.1 运行环境要求

| 组件 | 版本要求 |
| --- | --- |
| 操作系统 | Windows 10/11 或 Linux |
| JDK | 21 及以上 |
| MySQL | 8.0 |
| Redis | 7 |
| Node.js | 18+ |
| 微信开发者工具 | 最新稳定版 |

### 2.2 数据库初始化

1. 启动 MySQL 8.0，创建数据库：
   ```sql
   CREATE DATABASE shangcheng DEFAULT CHARACTER SET utf8mb4;
   ```
2. 导入项目根目录下的 `shangcheng.sql`：
   ```bash
   mysql -uroot -p shangcheng < shangcheng.sql
   ```
3. 修改后端配置 `application.yaml` 中的数据库地址、用户名、密码为本机实际值。

### 2.3 启动 Redis

```bash
redis-server
```

如 Redis 设置了密码，请在 `application.yaml` 的 `spring.data.redis` 下配置 `password`。

### 2.4 启动后端服务

在后端项目目录执行：

```bash
mvn clean package -DskipTests
java -jar target/soTokenspringBoot-0.0.1-SNAPSHOT.jar
```

服务默认监听 `8081` 端口，启动成功后控制台输出 `Started SoTokenspringBootApplication`。

### 2.5 启动 Web 管理后台

在 `前端/on` 目录执行：

```bash
npm install
npm run dev
```

按控制台提示访问本地开发地址（默认 `http://localhost:5173`）。生产构建执行 `npm run build`，产物在 `dist` 目录，可由 Nginx 托管。

### 2.6 启动微信小程序

1. 使用 HBuilderX 打开 `uni-app` 目录；
2. 执行「运行 → 运行到小程序模拟器 → 微信开发者工具」；
3. 在微信开发者工具中确认 AppID 与项目配置，编译预览。

## 第 3 章 普通用户操作说明

### 3.1 注册与登录

1. **注册**：在小程序登录页点击「注册」，输入用户名、密码、昵称，选择「普通用户」角色提交；
2. **账号登录**：输入用户名、密码登录；
3. **微信登录**：点击「微信一键登录」，系统自动获取 openid 完成登录并创建账号；
4. 登录成功后跳转至首页。

### 3.2 浏览与搜索商品

1. 进入「瞻途首页」查看品牌门户页面；
2. 首页包含以下功能区域：
   - **顶部导航**：品牌 Logo、分类导航、搜索框、购物车、登录入口；
   - **轮播/Hero 区**：品牌宣传 Banner，展示热门活动与推荐商品；
   - **商品分类**：12 个商品分类图标入口（数码、服饰、美食、家居等），点击跳转对应分类商品列表；
   - **限时秒杀**：展示正在进行的秒杀活动，含倒计时与商品卡片；
   - **瞻途精选**：支持热销榜、新品上架、品牌特卖等标签切换；
   - **平台介绍**：展示平台特色、购物流程、品质保障等信息；
   - **用户评价**：展示真实用户好评；
   - **资讯公告**：最新平台动态与行业资讯；
3. 顶部搜索框输入商品名称搜索；
4. 点击商品卡片进入商品详情，查看价格、库存、描述与评论。

### 3.3 收货地址管理

1. 进入「我的 → 收货地址」；
2. 点击「新增地址」填写姓名、手机号、详细地址；
3. 支持编辑、删除地址，下单时选择已存地址。

### 3.4 下单与支付

1. 在商品详情页选择购买数量，点击「立即购买」；
2. 选择收货地址，确认订单信息，提交订单；
3. 选择支付方式（微信支付 / 支付宝）完成支付；
4. 支付成功后订单状态更新为「已支付」。

### 3.5 订单管理

1. 进入「我的订单」查看全部订单；
2. 订单状态包括：待支付、已支付、已发货、已取消；
3. 已支付订单待商家发货后可查看快递单号；
4. 待支付订单可取消。

### 3.6 评论互动

1. 在商品详情页底部评论区域发表评论，可附带图片；
2. 点击他人评论的「回复」进行二级回复；
3. 点击「点赞」对评论点赞，再次点击取消。

### 3.7 即时通讯

1. 进入「消息」模块查看会话列表；
2. 选择商家或管理员发起会话；
3. 发送文本消息，对方在线时实时接收，离线时消息存库待读。

### 3.8 个人中心

- 修改头像、昵称、手机号、生日；
- 修改登录密码（需校验原密码，修改后需重新登录）；
- 退出登录。

## 第 4 章 商家操作说明

商家既可通过 Web 管理后台，也可通过小程序操作，以下以 Web 管理后台为主。

### 4.1 商家登录

使用商家账号登录 Web 管理后台，系统根据角色自动进入商家工作台。

### 4.2 商品管理

1. 进入「商品管理 → 商品列表」查看自有商品；
2. 点击「发布商品」填写名称、价格、库存、描述，上传主图；
3. 编辑已有商品信息，调整价格与库存；
4. 下架商品。

### 4.3 订单管理

1. 进入「订单管理」查看店铺订单；
2. 处理已支付订单，点击「发货」填写快递单号完成发货；
3. 查看订单详情与买家信息。

### 4.4 即时沟通

通过消息模块与下单用户实时沟通，解答售前售后问题。

---

## 第 5 章 管理员操作说明

### 5.1 管理员登录

使用管理员账号登录 Web 管理后台。

### 5.2 用户管理

1. 进入「用户列表」查看全部用户；
2. 对违规用户执行「封禁」操作，封禁期间用户无法登录；
3. 解封已封禁用户；
4. 调整用户角色（商家 / 普通用户）。

### 5.3 商品管理

查看全平台商品，可对违规商品下架处理。

### 5.4 订单管理

监控全平台订单状态，处理交易纠纷。

### 5.5 数据统计

进入「数据统计」查看销售总额、订单数量、订单趋势等可视化图表（基于 ECharts）。

---

## 第 6 章 即时通讯使用说明

1. 用户在商品详情或消息列表中发起与商家 / 管理员的会话；
2. 连接建立后系统推送当前在线用户列表；
3. 发送消息后，消息实时送达对方（在线）或存入数据库（离线）；
4. 支持文本与图片消息类型；
5. 通讯权限限制：普通用户仅可与商家或管理员通讯，避免用户间无关打扰。

## 第 7 章 常见问题

| 问题 | 解决方法 |
| --- | --- |
| 登录提示「账号已被封禁」 | 联系管理员申请解封 |
| 忘记密码 | 联系管理员重置，或通过原密码修改（若记得） |
| 下单失败提示库存不足 | 商品库存不足，联系商家补货或减少购买数量 |
| 支付成功但订单仍显示待支付 | 等待支付回调，或联系管理员核对支付记录 |
| WebSocket 消息收不到 | 检查网络连接，确认对方在线；离线消息可在重连后查看历史 |
| 微信登录失败 | 检查微信小程序 AppID/AppSecret 配置是否正确 |

## 第 8 章 维护与支持

- 后端日志：启动目录下控制台输出，可重定向至文件持久化；
- 数据库备份：定期使用 `mysqldump` 备份 `shangcheng` 数据库；
- Redis 维护：定期清理过期会话 Key；
- 版本升级：替换 jar 包并重启服务，前端重新构建部署。
