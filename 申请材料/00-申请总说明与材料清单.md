## 三、为申请软著所做的代码调整

为保证提交的源代码不泄露真实密钥、不包含第三方专有信息，同时完善品牌标识系统，已对源代码做了**最小化、可追溯**的调整，详细对照见 [05-代码修改说明.md](./05-代码修改说明.md)。摘要如下：

1. **微信小程序密钥脱敏**：`usercontroller.java` 中硬编码的 `appid` 与 `secret` 替换为占位符 `YOUR_WECHAT_APPID` / `YOUR_WECHAT_APPSECRET`，不影响代码逻辑，仅消除真实密钥泄露风险。
2. **数据库/缓存密码脱敏**：`application.yaml` 中 MySQL 密码替换为 `your_mysql_password`，注释中的 Redis 密码改为占位说明，避免真实口令进入公网材料。
3. **品牌标识系统建立**：新增 `brand.js` 配置文件与 `BrandLogo.vue` 组件，统一管理「瞻途」品牌名称、Logo、口号等信息，确保品牌一致性。
4. **首页内容丰富化**：将 Web 端首页内容从占位页面扩展为完整的电商门户页面（约 2400 行代码），包含导航、轮播、商品分类、限时秒杀、平台介绍等功能模块。
5. **品牌名称全局替换**：将各页面标题、导航栏等位置的通用名称替换为「瞻途」品牌名称。

以上调整均未改变软件的核心功能与架构，软件实际运行时通过本地配置文件或环境变量注入真实凭证。

## 四、注意事项

1. **文档转 PDF**：CPCC 线上系统接受 PDF 格式，请将各 `.md` 文件转换为 PDF（可使用 Typora、VS Code Markdown PDF 插件等）后上传，每份文档建议不超过 60 页。
2. **源代码格式**：源代码需合并为一份 PDF/Word，每页不少于 50 行，页眉标注「软件名称 V1.0」及页码，前 30 页为开头、后 30 页为结尾，不足 60 页则全部提交。具体规则见 [04-源代码提交说明.md](./04-源代码提交说明.md)。
3. **申请人信息**：申请表中的「著作权人」姓名/名称、证件号、联系方式需与身份证明一致，请由申请人本人填写，本材料中以「【请填写】」标记的字段均为待填项。
4. **未发表声明**：若软件尚未对外发布，请在申请表「发表状态」选择「未发表」；本项目默认按「未发表」处理。
5. **保留原始代码**：脱敏前后的代码请分别留存，登记审查期间如版权中心要求补充说明，可据此回复。
