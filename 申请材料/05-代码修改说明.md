## 三、修改详情

### 3.1 usercontroller.java —— 微信小程序密钥脱敏

**文件路径**：`java/src/main/java/org/example/sotokenspringboot/controller/usercontroller.java`

**修改位置**：`wxlogin` 方法内（原第 197~200 行）

**修改前**：

```java
@GetMapping("wxlogin")
public Result<Object> wxlogin(String code){
    System.out.println(code);
    String response=wxopenfeign.getTest("wxa26249f17669e149",
            "4784dac93475932e0f1ff5705e88e4aa", code,
            "authorization_code");
```

**修改后**：

```java
@GetMapping("wxlogin")
public Result<Object> wxlogin(String code){
    System.out.println(code);
    // 微信小程序 appid 与 secret 应通过配置文件注入，此处为占位符（详见《05-代码修改说明.md》）
    String response=wxopenfeign.getTest("YOUR_WECHAT_APPID",
            "YOUR_WECHAT_APPSECRET", code,
            "authorization_code");
```

**修改原因**：

- 原 `appid`（`wxa26249f17669e149`）与 `secret`（`4784dac93475932e0f1ff5705e88e4aa`）为真实的微信小程序凭证，提交软件著作权登记材料后会进入公开档案，存在凭证泄露风险；
- 替换为 `YOUR_WECHAT_APPID` / `YOUR_WECHAT_APPSECRET` 占位符，代码逻辑完全不变，仅字面值替换；
- 生产部署时，建议将上述凭证迁移至 `application.yaml` 通过 `@Value` 注入，本说明登记的修改不阻断后续优化。

**功能影响**：无。微信登录流程（`code2session` 换取 openid → 查询/注册用户 → 签发 Token）保持原样。

### 3.2 application.yaml —— MySQL 数据库密码脱敏

**文件路径**：`java/src/main/resources/application.yaml`

**修改位置**：`spring.datasource` 配置段

**修改前**：

```yaml
  datasource:
    url: jdbc:mysql://localhost:3306/shangcheng?useSSL=false&serverTimezone=UTC&characterEncoding=utf8
    username: root
    password: lll000
    driver-class-name: com.mysql.cj.jdbc.Driver
```

**修改后**：

```yaml
  datasource:
    url: jdbc:mysql://localhost:3306/shangcheng?useSSL=false&serverTimezone=UTC&characterEncoding=utf8
    username: root
    password: your_mysql_password
    driver-class-name: com.mysql.cj.jdbc.Driver
```

**修改原因**：原 `lll000` 为真实数据库口令，脱敏为 `your_mysql_password` 占位符，避免口令随登记材料公开。

**功能影响**：无。部署时填入实际密码即可正常连接数据库。

### 3.3 application.yaml —— Redis 密码注释脱敏

**文件路径**：`java/src/main/resources/application.yaml`

**修改位置**：`spring.data.redis` 配置段

**修改前**：

```yaml
  data:
    redis:
      host: 127.0.0.1
      port: 6379
      database: 0
#      password: lll060503.
```

**修改后**：

```yaml
  data:
    redis:
      host: 127.0.0.1
      port: 6379
      database: 0
      # 密码请通过环境变量或本地配置注入，提交材料时已脱敏（详见《05-代码修改说明.md》）

```

**修改原因**：原注释中包含真实 Redis 口令 `lll060503.`，虽为注释仍会随源码公开，故一并脱敏并补充说明注释。

**功能影响**：无。该行本即为注释，未参与运行。

8. **六大平台优势**：图标 + 描述卡片；
9. **购物流程图解**：6 步流程可视化；
10. **品质保障承诺**：6 项服务保障；
11. **用户好评展示**：评分汇总 + 3 条评价；
12. **瞻途动态资讯**：3 条资讯卡片；

14. **合作伙伴区**：8 个合作伙伴 Logo；

- 原首页内容过于简单，无法体现电商平台的完整功能与品牌形象；

## 四、未修改项说明

以下内容虽存在代码风格问题，但**不属于敏感信息**，为保证登记材料与实际代码一致、减少改动风险，**未做修改**：

1. **类名命名风格**：部分类名采用小驼峰（如 `usercontroller`、`usersvice`、`goodsMismapper`），与 Java 大驼峰惯例不符，但不影响功能，未修改；
2. **SQL 建表字段大小写**：`order` 表中 `buyNum`、`good_id` 等字段大小写混合，属历史命名，未修改；
3. **第三方依赖**：`uni-app/uni_modules/` 为第三方组件，非本软件原创代码，不纳入登记范围，无需修改；
4. **编译产物**：`unpackage/dist/` 目录为构建产物，不纳入登记范围；
5. **后端业务逻辑**：所有后端接口、数据库操作、业务逻辑均未修改，品牌相关改动仅涉及前端展示层与配置层；
6. **小程序端代码**：本次品牌更新未涉及 uni-app 小程序端代码，移动端品牌标识将在后续版本中统一更新。

1. 在 `application.yaml` 中将 `password` 还原为本机真实 MySQL 密码；
