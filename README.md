# 瞻途电商交易系统软件 V1.0

> **品牌口号**：前瞻未来 · 途享好物
>
> 一套面向「管理员—商家—用户」三角色协同的电子商务交易系统，支持 Web 管理后台与微信小程序移动端双端运行。

---

## 一、项目简介

「瞻途电商交易系统软件」是一套覆盖商品发布、在线下单、支付、发货、评价、即时通讯及后台运营管理全链路的电商解决方案。系统以 Spring Boot + Vue 3 + uni-app 为技术栈，后端采用 MVC 三层架构，通过 Sa-Token 完成认证授权，通过 WebSocket 实现实时通讯，数据持久化采用 MySQL 8.0，缓存与会话采用 Redis。

- **软件全称**：瞻途电商交易系统软件
- **软件简称**：瞻途（ZHAN TU）
- **版本号**：V1.0
- **开发方式**：独立开发
- **源程序量**：约 15000 行

## 四、功能模块

### 4.1 品牌门户首页

Web 端首页作为「瞻途」品牌门户入口，采用简约清新风格，包含：

- 顶部导航栏（品牌 Logo、分类导航、搜索框、登录注册）
- Hero 品牌展示区（品牌口号、平台数据统计）
- 商品分类导航（12 大品类入口）
- 限时秒杀（倒计时 + 商品卡片）
- 精选好物（标签切换 + 商品网格）
- 平台服务保障（六大承诺）
- 商家入驻引导
- 完整页脚信息

### 4.2 用户与权限管理

- 账号密码登录、微信小程序登录（OpenFeign 调用 code2session）
- 基于 Sa-Token 的三角色权限隔离（admin / merchant / user）
- 用户信息维护（昵称、手机号、头像等）
- 用户状态管理（正常 / 封禁 / 注销 / 未激活）

### 4.3 商品管理

- 商家发布商品（名称、价格、库存、描述、主图）
- 商品列表分页查询、按名称搜索
- 商品详情展示
- 库存管理（下单扣减、取消回滚）
- 管理员审核与下架

### 4.4 订单管理

- 用户下单生成订单（全局唯一订单号）
- 订单状态流转：待支付 → 已支付 → 已发货 → 已取消
- 商家填写快递单号完成发货
- 订单快照（冗余收货人信息，保证历史数据一致性）
- 多角色订单查询（用户 / 商家 / 管理员）

### 4.5 在线支付

- 微信支付、支付宝支付
- 支付状态：待支付 / 已支付 / 支付失败 / 已退款
- 支付记录与订单通过 order_id 唯一关联
- 第三方支付回调处理

### 4.6 收货地址管理

- 多地址维护（姓名、手机号、详细地址）
- 下单时关联地址 ID，并将地址快照写入订单表

### 4.7 评论互动

- 一级评论（支持配图）
- 二级回复
- 评论点赞（唯一索引防重复）
- 评论树形展示

### 4.8 即时通讯（IM）

- 基于 Spring WebSocket 的全双工通信
- 会话管理（用户 ID 与会话映射）
- 消息类型：TEXT 文本、IMAGE 图片
- 聊天类型：PUBLIC 公开、PRIVATE 私聊
- 在线用户广播
- 消息持久化（im_message 表）

### 4.9 后台管理

- **管理员端**：用户管理、商品管理、订单管理、数据统计可视化（ECharts）
- **商家端**：商品管理、订单处理、经营数据查看
- **用户端**：商品浏览、订单查询、个人信息

## 六、关键技术实现

### 6.1 Sa-Token 认证授权

- `StpUtil.login(userId)` 签发 Token，有效期 30 天
- `SaInterceptor` 拦截器配合 `SaRouter` 实现路由级鉴权
- `StpInterfaceImpl` 实现角色与权限加载
- 支持多端同时在线、账号封禁校验

### 6.2 WebSocket 即时通讯

- `WebSocketConfig` 注册 `/ws/chat` 端点
- `WebSocketSessionManager` 维护用户与会话映射
- `ChatWebSocketHandler` 处理 CONNECT 与 MESSAGE 消息
- 在线用户列表实时广播

### 6.3 全局唯一订单号

`OrderIdUtil` 基于雪花算法思想生成 19 位全局唯一订单号，保证高并发下不重复。

### 6.4 品牌标识系统

- `brand.js`：集中管理瞻途品牌信息（名称、口号、描述、分类、商品等）
- `BrandLogo.vue`：可复用的 SVG 品牌 Logo 组件，支持自定义尺寸与显示选项
- 全局统一品牌展示，确保一致性

## 七、快速开始

### 7.1 环境要求

| 类别 | 要求 |
| --- | --- |
| JDK | 21 及以上 |
| MySQL | 8.0 |
| Redis | 7 |
| Node.js | 18+ |
| Maven | 3.8+ |
| 微信开发者工具 | 最新稳定版（小程序端） |

### 7.2 后端启动

```bash
# 1. 导入数据库
#    执行 java/src/main/resources 下的 SQL 脚本

# 2. 修改配置
#    编辑 java/src/main/resources/application.yaml
#    配置 MySQL、Redis、微信 AppID 等信息

# 3. 启动服务
cd java
mvn spring-boot:run
#    服务默认监听 8081 端口
```

### 7.3 Web 前端启动

```bash
cd vue
npm install
npm run dev
#    访问 http://localhost:5173
```

### 7.4 微信小程序启动

```bash
# 1. 使用 HBuilderX 打开 uni-app 目录
# 2. 执行「运行 → 运行到小程序模拟器 → 微信开发者工具」
# 3. 在微信开发者工具中确认 AppID 与项目配置
```

### 7.5 生产构建

```bash
# 后端打包
cd java
mvn package -DskipTests
java -jar target/soTokenspringBoot-0.0.1-SNAPSHOT.jar

# 前端打包
cd vue
npm run build
#    产物在 dist 目录，可由 Nginx 托管
```
